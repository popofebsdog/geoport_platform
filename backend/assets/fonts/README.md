# Report Font

Project previews, PDF and editable Word reports use Iansui, a freely redistributable Traditional Chinese Kai-style font, at 12pt. The user selected this deployable alternative to a separately licensed system BiauKai font.
Source: https://github.com/ButTaiwan/iansui
Upstream revision: 9d9a8e68bf1e138dd91e562eeff28d95bca33196
The accompanying Iansui-OFL.txt must remain with the font when redistributing this application.
Iansui-Regular.ttf is the unmodified upstream static font. The frontend WOFF2 is a losslessly compressed version of the same face, generated with fontTools 4.68.0 and Brotli 1.2.1; no glyphs are removed or renamed. It is loaded only with the report UI. No proprietary system font is redistributed.
